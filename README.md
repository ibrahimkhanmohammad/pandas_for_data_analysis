# Pandas for Data Analysis

A hands-on learning repository documenting my journey of learning **Pandas**, a powerful Python library for data manipulation, cleaning, and analysis.

This repository contains practical examples, code snippets, and exercises covering the fundamentals of Pandas and essential data analysis operations.

## What I Learned

### 01. Pandas Series
- Creating Pandas Series
- Understanding Series structure
- Indexing and accessing elements
- Basic Series operations

### 02. DataFrames
- Creating DataFrames
- Understanding rows and columns
- Accessing and selecting data
- Basic DataFrame operations

### 03. Importing Data
- Importing datasets into Pandas
- Reading external data files
- Exploring imported datasets

### 04. Filtering and Sorting
- Selecting rows and columns
- Conditional filtering
- Boolean indexing
- Sorting data

### 05. Aggregation and Grouping
- Statistical operations
- Calculating mean, median, sum, minimum, and maximum
- Grouping data
- Aggregating values

### 06. Data Cleaning
- Identifying missing values
- Handling missing data
- Removing duplicate records
- Preparing datasets for analysis
